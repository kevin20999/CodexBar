# Fork Origin

CodexTokenBar is based on the original [CodexBar](https://github.com/steipete/CodexBar) project.

## Upstream attribution

- Original project: [steipete/CodexBar](https://github.com/steipete/CodexBar)
- Original author: Peter Steinberger
- Original license: MIT

This repository is not a clean-room rewrite. It starts from the CodexBar codebase and keeps visible attribution to that upstream project.

## Why this fork exists

The goal of CodexTokenBar is to take the original project foundation and reshape it into a narrower product:

- focus on Codex / OpenAI dashboard data
- emphasize quota, token, credits, and code review visibility
- use separate branding, packaging, and release management

## How this fork differs from the original

The original CodexBar project is a broader multi-provider menu bar app.

CodexTokenBar is being documented and packaged as a more focused fork. In practice, that means this repository may:

- remove or de-emphasize upstream features that are outside the Codex / OpenAI focus
- keep fork-specific UI, naming, and packaging decisions
- evolve on a different release cadence than the upstream project

## Practical guidance

- If you want the original project and its upstream release channel, use [CodexBar](https://github.com/steipete/CodexBar).
- If you are working in this repository, keep upstream attribution visible in public-facing docs.
- When publishing screenshots, release notes, or project pages for this fork, include a short note that it is based on CodexBar and link back to the original repository.
